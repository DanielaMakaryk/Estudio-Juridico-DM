# Estudio Jurídico DM & Asociados ⚖️✨

Plataforma web corporativa e institucional diseñada para la gestión de marca digital, servicios legales y atención al ciudadano.

### 🚀 Características del Proyecto:
* **Diseño Institucional de Alto Impacto:** Interfaz sobria, formal y profesional, optimizada para transmitir confianza jurídica y claridad informativa.
* **Estructura de Servicios:** Distribución estratégica de las distintas áreas del derecho (civil, laboral, comercial, etc.) para una rápida orientación del cliente.
* **Canales de Consulta:** Integración de componentes visuales directos para facilitar el contacto, asesoramiento y reserva de entrevistas legales.

### 🛠️ Tecnologías utilizadas:
* HTML5 (Maquetación semántica y accesible).
* CSS3 (Estilos corporativos y diseño adaptabilidad responsiva).
* JavaScript puro (Interactividad fluida en el área de usuario).
